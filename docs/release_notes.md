# v0.2.0 — installable preview

From the read-only seed prototype to a reversible installed policy runtime: 99 scoped rules, Codex/Claude/OpenCode adapter contracts, context restoration, concurrent project pins, evidence/review/CAS evolution, exact-path exceptions, safe JSON formatting, optional authenticated local service, commit-pinned remote candidate discovery, and private whitepaper import.

Includes a deterministic source distribution and a **private ChatGPT skills preview**. Public MCP implementation and production package builder are present; actual hosting, developer/domain verification, recorded end-to-end review cases and official approval remain external prerequisites. No fake URL or approved listing is claimed.

Cross-platform CI verifies Python behavior, real local RPC and OpenCode subprocess adapter contracts, JavaScript/MCP behavior, reproducible packaging and policy/source integrity. This is not a certificate that authenticated Codex/Claude/OpenCode model sessions were exercised on the owner's PC. Native host trust remains intact. The suite does not prove universal model compliance or all shell-side-effect containment.

Installation selects an already installed compatible Python and never installs a large toolchain or forces a daemon. The public source contains curated owner rules and R01–R71 with traceability, not the raw uploaded whitepaper, credentials, personal profile data or project source.
